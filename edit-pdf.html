How to Add Text to a PDF Online (Forms, Notes, Dates)

By AllToolsPro · Updated 12 October 2026 · 5 min read

Many PDFs are not meant to be edited at all, yet you still need to put something on them: your name on a form, today's date beside a signature line, a short note for a colleague, or a missing figure in a table. Printing, writing by hand and re-scanning is slow and produces a poorer copy.

The AllToolsPro Edit PDF tool is a straightforward text-adding editor. It lets you click anywhere on a page, type, and save a new PDF. This guide shows how to use it and explains clearly what it is, and is not, designed to do.

What kind of editing this is

It helps to be precise. A PDF stores each page as positioned content rather than as a flowing document, so changing existing sentences is a very different job from adding new ones. This tool does the second job. It places new text over the page at the spot you click. It does not change or delete the text, images or layout already in the file.

That makes it ideal for filling in non-interactive forms, labelling pages, adding reviewer comments or dates, and similar tasks. It is not a replacement for a full desktop editor if you need to rewrite existing paragraphs.

Adding text step by step

  1. Open the Edit PDF tool and choose your file in the upload box that invites you to add text, signatures or notes.
  2. Wait for the pages to appear. Every page of the PDF is shown one under another and you scroll down to move through them.
  3. In the toolbar, the Add Text tool is already active. Choose a colour with the colour swatch and set a size in the number box. The default size is 18.
  4. Click the exact spot on the page where you want the text to start. A small box asks you to enter the text.
  5. Type the text and confirm. It appears on the page in the colour and size you chose. Repeat on as many spots and pages as you need.
  6. Press Save & Download. The edited document downloads as Edited_AllToolsPro.pdf.

Practical ways to use it

  • Filling flat forms. If a form is just an image or a plain PDF with no fillable fields, click on each blank line and type your answer.
  • Dates and reference numbers. Add a submission date or application number to a cover page.
  • Review notes. Place short comments next to a paragraph in a draft and send it back.
  • Typed signature lines. You can type a name beside a signature line. Be aware that typed text is not a handwritten or digital signature and may not be accepted where a formal signature is required.

Tips for neat results

  • Decide size before you click. Set the size and colour first. Each piece of text keeps the settings it was added with, so you can use different sizes in different places.
  • Match the surrounding text. For form fields, a size of 10 to 14 usually looks closer to the printed text than the default of 18.
  • Choose a readable colour. Black or dark blue works on white pages. On dark or photographic pages, use a light colour.
  • Plan one click per line. The text starts where you click and extends to the right, so click at the left end of the blank space.
  • Check the saved file. Open the download and zoom in. Placement can differ by a few pixels from what you saw on screen.

Limitations to know about

  • No undo or delete. The editor has no button to remove text once it is placed. If you make a mistake, reload the page and start over, or avoid saving that version.
  • Add-only. You cannot change, erase or move content that is already in the PDF.
  • Basic font. New text is drawn using a standard built-in font. Letters, numbers and common punctuation work. Characters from other scripts, such as Hindi, may not be supported.
  • Password-protected files. These usually cannot be opened. Remove the password first.

Privacy

The pages are displayed and the new text is written into the file entirely in your browser. The document is not uploaded for processing, which is helpful when the form contains personal details such as addresses, ID numbers or financial information. Close the tab when you finish, and avoid leaving the edited file in shared folders.

In short

Use this tool for what it does well: quickly putting typed information on top of an existing page. Set your size and colour, click carefully, and check the final file. For anything beyond that, such as rewriting existing content, choose a full editor.

Frequently asked questions

Can I edit the existing text in my PDF?

No. The tool adds new text on top of the page. It cannot change or remove text and images that are already in the document.

Can I undo text I added by mistake?

There is no undo button. If you make a mistake before saving, reload the page and start again, then save only when you are happy.

Can I add more than one piece of text?

Yes. Click as many places on as many pages as you like. Each piece keeps the colour and size that were set when you added it.

What is the saved file called?

It downloads as Edited_AllToolsPro.pdf. Rename it to something meaningful after saving.
