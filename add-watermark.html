How to Add a Text Watermark to a PDF Online

By AllToolsPro · Updated 12 October 2026 · 5 min read

A watermark is a line of text or a logo placed on the pages of a document to say something about it: that it is a draft, that it is confidential, or simply who it belongs to. You see them on contracts under review, price lists sent to prospects, exam papers and portfolio samples.

This guide explains when a watermark is worth adding, how to apply a text watermark to every page of a PDF with the AllToolsPro Add PDF Watermark tool, and how to choose settings that stay readable without ruining the document underneath.

Why people watermark PDFs

A PDF is designed to look the same everywhere, which also means it is easy to forward. A watermark travels with the file and tells every reader how to treat it. Common reasons include:

  • Status labels. Words such as DRAFT, FOR REVIEW or NOT FOR DISTRIBUTION stop an unfinished version from being mistaken for the final one.
  • Confidentiality. CONFIDENTIAL or INTERNAL USE reminds recipients that the content is not meant to be shared widely.
  • Ownership. A photographer, designer or tutor can put a name across sample pages so the preview is useful but not a substitute for the paid version.
  • Tracing copies. Putting a recipient's name on the copy you send them makes it clear where a leaked file came from.

Adding a watermark step by step

The tool works on one PDF at a time and applies the same text to every page. Here is the flow as it appears on screen:

  1. Open the Add PDF Watermark tool and choose your file in the Select PDF File box (click it or drop the file on it).
  2. When the settings panel appears, type your text into the Watermark Text field. If you leave it empty, the tool falls back to the text AllToolsPro, so always type your own wording.
  3. Set the Font Size slider. It runs from 10 to 150 and starts at 50.
  4. Set Opacity from 0.1 (very faint) to 1.0 (solid). The starting value is 0.3.
  5. Set Rotation from 0 to 360 degrees. The default of 45 gives the familiar diagonal stamp.
  6. Pick a Text Color. The default is a mid grey-blue, which is a safe choice on both white and tinted pages.
  7. Press Add Watermark & Download. The new file is saved with the prefix Watermarked_ in front of your original file name.

Your original is never altered, so you can run the tool again with different settings if the first attempt is not quite right.

Choosing settings that actually work

The usual failure is a watermark that is either invisible or so strong that it makes the page hard to read. A few guidelines help:

  • Keep opacity between 0.2 and 0.4 for body text. The mark should be noticeable at a glance but should not fight with the words behind it.
  • Use a neutral colour. Mid grey works on most pages. Red can suit a DRAFT stamp, but at full opacity it is tiring to read through.
  • Match size to text length. A short word like DRAFT looks good at 80 to 120. A long phrase at that size can run past the page edge, so lower the size as the text gets longer.
  • Test on a small copy first. For a long document, try the settings on a two or three page extract and check the result before processing the whole file.

What to know about how the mark is placed

It helps to understand what the tool does so the result is not a surprise. It places one line of text per page, starting from an approximate centre point, and rotates it from that starting point. It does not tile the text across the page. Because the text is anchored near the middle and then rotated, very long text or unusual angles such as 90 or 180 degrees can end up off-centre or partly outside the page.

The text is drawn in a standard bold sans-serif font built into PDF software. That font covers ordinary Latin letters, numbers and common punctuation. Characters from other scripts, such as Hindi or Arabic, are not supported by that font and can make the process fail. If you need a watermark in another script, use a tool that embeds a suitable font instead.

Common mistakes and troubleshooting

  • Expecting tamper-proof protection. A watermark is a visible label, not a lock. Someone with a PDF editor can remove or cover it. If the document is truly sensitive, combine the watermark with proper access controls rather than relying on it alone.
  • Watermarking the only copy. Always keep an unmarked original. Re-opening the output to remove the mark later is not something you want to depend on.
  • An error message after pressing the button. This usually means the file is password-protected, damaged, or the text contains characters the font cannot draw. Remove the password first, or simplify the text to plain letters and numbers.

Privacy and file handling

The watermark is applied by code running in your own browser. The PDF is read from your device, modified in memory and handed back as a download, so the file is not sent to a server for processing. That is useful when the reason for the watermark is that the document is confidential in the first place.

A quick wrap-up

A good watermark is short, readable and clearly intentional. Type your own wording, keep the opacity low, check the first page of the output, and keep your original safe.

Frequently asked questions

Is the watermark added to every page?

Yes. The same text, size, opacity, angle and colour are applied to every page of the PDF. You cannot choose individual pages in this tool.

Can I use an image or logo as a watermark?

No. This tool adds text only. For a logo you would need a tool that places images on PDF pages.

Will the original file be changed?

No. The tool creates a new file named Watermarked_ followed by the original file name. Your original stays as it was.

Can the watermark be removed by someone else?

It can be. A watermark is a visible label, not security. Anyone with a capable PDF editor may be able to remove or cover it, so do not rely on it to protect sensitive content.
