QR Code Generator: Make a Scannable Code for Links, Text and Wi-Fi

QR codes are now part of everyday life in India, from shop counters to restaurant menus and event posters. Behind the scenes, a QR code is simply a square pattern that stores a piece of text, most often a web address. Your phone camera reads the pattern and acts on the text.

The QR Code Generator turns whatever you type into such a pattern, instantly and without sign-up. Below you will find how to use it, how to choose colors safely, and how to avoid the mistakes that make a code refuse to scan.

What this tool creates

You type or paste a link or any text, and the tool draws a QR code that updates live as you type. It creates what is called a static QR code: the content is baked directly into the pattern. There is no tracking, no expiry and no account involved. Once you download the image, it will keep working as long as the destination does.

The tool uses the highest error-correction level, which means a code can still be read when part of it is dirty or slightly damaged. The trade-off is that it looks denser than a code with lower correction.

How to make a QR code, step by step

  1. Click the box labelled Enter URL or Text and paste your link or type your message.
  2. Watch the preview on the right. It shows "Waiting for text..." until you enter something.
  3. Choose QR Color and Background if you want something other than black on white.
  4. Click Download PNG to save the image.
  5. Scan it with your phone before using it anywhere public.

If you press download with an empty box, the tool will ask you to enter some text first.

Useful things to put in a QR code

  • Website or social profile: include the full address starting with https:// so phones recognise it as a link.
  • Google Maps location: paste a share link so customers can find your shop.
  • WhatsApp chat link: paste a wa.me link so customers can message you without saving your number.
  • Plain text: a short note, a coupon code or an address.
  • Wi-Fi details: the tool has no dedicated Wi-Fi form, but you can type the standard Wi-Fi text format yourself, for example WIFI:T:WPA;S:NetworkName;P:YourPassword;;. Test it on a phone before printing, and remember that anyone who scans it gets your password.

Tips for a code that always scans

  • Keep strong contrast. A dark code on a light background is the safest. Avoid pale or low-contrast colors, and do not invert the colors so the code is lighter than the background, as many scanners cannot read that.
  • Keep the empty border around the code. Do not crop it tight or place text against it.
  • Shorter content scans more easily. A long link makes a denser pattern. Use a short link where you can.
  • Do not stretch it. Resize the image evenly.
  • Test on more than one phone and in the lighting where it will be used.

Printing and size guidance

The downloaded PNG is a modest 200 by 200 pixel image. That is fine for screens, WhatsApp status images and small documents. For a poster or banner, enlarging it will make the edges soft, which can hurt scanning from a distance. As a rough guide, scanning distance should be much greater than code width, so a code meant to be read from a few metres away needs to be printed large. If you need very large print, place the image at a size where it still looks sharp and always test a physical print.

Common mistakes and troubleshooting

The code will not scan. Check contrast, size and the border. Make sure the link is correct and loads normally on your phone.

It opens as plain text. The link was probably typed without https://, so the phone treated it as text.

You changed the link after printing. A static QR code cannot be edited. If the content changes, you must generate and print a new code.

The preview did not refresh. The color pickers update the code when you finish choosing a color, so confirm the selection.

Privacy, safety and limits

The code is generated in your browser and the tool says that your data is not stored on its servers. Be mindful of what you encode: anyone who scans can read it, so never put passwords or private information in a QR code meant for public places. Also, when you scan codes from others, look at the address your phone shows before opening it.

The tool does not offer scan analytics, editable dynamic codes, logo embedding or vector downloads. If you need to track scans or change the destination later, you would need a dynamic QR service. For permanent links and simple jobs, a static code is reliable and free.

No. Static codes cannot be edited. Create and print a new code if the destination changes.

Why won't my colored QR code scan?

The most common cause is weak contrast. Use a dark code on a clearly lighter background, and avoid reversing the colors.
