How to Split a PDF by Page Range Without Installing Anything

A 120-page PDF is rarely what you actually need to send. Maybe it is only chapter four of a textbook, the last three pages of a contract, or the single section a colleague asked about. Splitting lets you cut out exactly that part as a smaller, separate file.

This article covers how the Split PDF tool works, what it can and cannot do, and how to avoid the small mistakes that waste time.

What the Split PDF tool does

The tool takes one PDF and produces a new PDF containing a continuous range of pages that you choose, by entering a starting page and an ending page. Your original file stays as it is. Think of it as cutting a slice out of the document.

It works with one range at a time. If you need several separate slices, you simply run it again with a different range, which is quick because the steps are short.

How to split a PDF, step by step

  1. Click Select PDF File (the box reads "Choose the file you want to split") and pick your document.
  2. The page confirms the file name and total page count, for example "File loaded" with the number of pages.
  3. Under Enter Page Range to Extract, type the first page in the From box and the last page in the To box. The To box is pre-filled with the last page of the document.
  4. Click Extract Pages & Download.
  5. A file named like Split_Pages_5_to_12_AllToolsPro.pdf is saved to your device, so the page range is visible in the file name.

To take the first five pages, enter 1 and 5. For the last ten pages of a 40-page file, enter 31 and 40.

Where splitting is useful

  • Exam and scholarship portals: Upload only the relevant pages of a long certificate or prospectus rather than the entire file.
  • Students: Pull a single chapter from a big reference PDF to read on your phone or share with a study group.
  • Offices and accountants: Separate one month's statement from a combined annual document.
  • Legal and property paperwork: Send only the signature page or schedule that someone has asked for, instead of the whole agreement.

Tips for accurate results

  • Count pages from the PDF's own numbering, not the printed page numbers. A book may have roman-numeral front matter, so printed page 1 can be PDF page 9.
  • Open the original in a viewer first and note the exact start and end pages.
  • Use the file name of the output to confirm the range, then open it and check the first and last pages.
  • If the result is still too big for an upload limit, compress it as a second step.

Troubleshooting common issues

"Please enter a valid page range." This message appears when a box is empty, the From number is below 1, the To number is higher than the page count, or From is greater than To. Correct the numbers and try again.

"Error loading PDF." The page suggests the file might be password protected. Remove the password in the original software and upload it again.

Nothing happens after choosing a file. The tool only accepts files that the browser recognises as PDF. Check the extension and try again.

Planning your split before you start

A little planning makes splitting almost effortless. Decide what the recipient truly needs, then open the PDF in any viewer and scroll to the first and last pages of that section. Write the two numbers down. Entering them takes seconds, and you avoid downloading several attempts.

If the section you want sits in the middle of the document, such as pages 14 to 22, simply enter those two numbers. If you need two separate sections, for example pages 1 to 3 and pages 50 to 52, you have two options: run the tool twice and merge the outputs, or use an extract-pages tool and enter both ranges at once.

Naming matters too. The downloaded file already includes the range in its name, which helps you keep track, but consider renaming it to something meaningful, such as the subject and month, before you send it. Recipients appreciate clear file names far more than they notice the tool you used.

Is it private?

Yes, in design. The PDF is read and processed inside your browser, and the page notes that no files are uploaded. For documents carrying personal details, such as identity proofs or bank statements, that local processing is reassuring. Still, close the tab and delete unneeded downloads when you are finished, especially on a shared device.

Limits and alternatives

This tool produces one continuous range per run. It does not split a document into many equal parts in one go, does not split by file size, and does not pick scattered pages like 2, 7 and 15. For non-consecutive pages, use an extract-pages tool, which accepts comma-separated lists. To delete pages instead of keeping them, a remove-pages tool is a better fit. For very large files, remember that your browser must hold the document in memory, so older phones may struggle.

Frequently asked questions

Is the Split PDF tool on AllToolsPro free to use?

Yes. Split PDF is completely free on AllToolsPro. There is no registration, no signup and no watermark, and it works on mobile phones and computers.

Can I split a PDF into several files at once?

No. The tool creates one file from one continuous page range per run. Run it again for each additional range.

Does splitting change my original PDF?

No. The original stays untouched and a new file is downloaded.

Can I pick pages that are not next to each other?

Not with this tool. Use an extract-pages tool, which allows lists such as 1, 5, 9-12.

Why does it say my page range is invalid?

The From value must be at least 1, the To value cannot exceed the total pages, and From cannot be greater than To.

Is my file uploaded anywhere?

The page states that processing happens in your browser and nothing is uploaded.
