# AllToolsPro

Free online PDF, image, AI and utility tools — https://www.alltoolspro.in

Static site (plain HTML/CSS/JS, hosted via GitHub Pages, domain in `CNAME`).
- Each tool is a root-level `<tool>.html`; shared styles in `alltoolspro-tool.css`.
- When adding a tool: add it to `all-tools.html`, `index.html` and `sitemap.xml`.
